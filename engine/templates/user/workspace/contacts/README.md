# Contacts

One file per person (or recruiter firm) you are in conversation with: who they are, what was sent
and said and when, and what to do next. **Read the person's file before writing to them, and add a
dated line after every exchange.**

Each file's frontmatter ends with `schema_version: 3` (`engine/docs/RECORD_SCHEMA.md`) and carries
`org_profile:` (the matching record in `../organizations/`, if any), `applications:` (the folder
holding what was sent) and a one-line `summary` of where things stand.
